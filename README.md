# PrivateRide

Invitation-only ride-hailing platform for private communities (Bulgaria,
BGN/EUR, bg/en). TypeScript monorepo: NestJS API, Expo mobile app, Next.js
admin, PostgreSQL + PostGIS, Redis.

- [documentation/DEVELOPMENT_PLAN.md](documentation/DEVELOPMENT_PLAN.md) — milestone status
- [documentation/ARCHITECTURE.md](documentation/ARCHITECTURE.md) — design and decisions
- [documentation/SECURITY.md](documentation/SECURITY.md) — security model, GDPR, legal caveats
- [documentation/DEPLOYMENT.md](documentation/DEPLOYMENT.md) — run, test, deploy

Quick start: see DEPLOYMENT.md. API docs at `/docs` when running locally.
