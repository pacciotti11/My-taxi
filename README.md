Тестова версия за Android: свали APK-то на телефона, разреши инсталиране от
неизвестен източник и свържи приложението със сървъра си
([инструкции](documentation/TESTING_ANDROID.md)).

Invitation-only ride-hailing platform for private communities (Bulgaria,
BGN/EUR, bg/en). TypeScript monorepo: NestJS API, Expo mobile app, Next.js
admin, PostgreSQL + PostGIS, Redis.
